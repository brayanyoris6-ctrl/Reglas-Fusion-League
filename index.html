Reglas Generales
🧤 Regla de Goaltending (GT)
👥 1. Jugadores
  • Solo podrán entrar 2 jugadores como máximo al área propia.
  • Uno de ellos deberá ser obligatoriamente el CM.
🟩 2. Área Chica
  • Únicamente el CM podrá entrar al área chica.
🦘 3. Saltos
  • El CM podrá realizar un máximo de 2 saltos dentro del área chica.
  • Si realiza un tercer salto, se considerará GT.
📹 4. Evidencia
  • Toda reclamación de GT deberá contar con clip de la jugada completa.
⚠️ Regla de Default (DF)
📢 1. DT / Sub-DT No Responde
  • Si el DT o Sub-DT no responde al ping, se deberá esperar 25 minutos desde la hora oficial del partido para reclamar DF.
💬 2. DT / Sub-DT Responde
  • Si el DT o Sub-DT responde pero no se une al partido, se deberá esperar 35 minutos desde la hora oficial.
🚨 3. Reclamación y Evidencia
  • Cumplido el tiempo correspondiente, se podrá solicitar el DF.
  • Evidencia Obligatoria: Presentar capturas de los pings y del tiempo de espera transcurrido.
  • ❌ Prohibido reclamar DF antes de cumplir el tiempo establecido.
⏳ Time Waste & 💥 Shotstack
⏳ Regla de Time Waste
  • Prohibición: Queda prohibido realizar Time Waste intencionadamente para consumir tiempo.
  • Posesión: No se podrá mantener el balón sin intención de avanzar o realizar una jugada solo para hacer pasar el tiempo.
  • Evidencia: Clip de la jugada completa obligatorio.
💥 Regla de Shotstack
  • Prohibición: Prohibido realizar Shotstack mediante combinaciones de habilidades o mecánicas para ejecutar disparos no permitidos.
  • Combinaciones: No se podrán usar mecánicas que permitan saltarse las restricciones normales de un disparo.
  • Evidencia: Demostrar con clip de la jugada completa.
Reglamento de Estilos 🟢・RAROS
ISAGI / NEL ISAGI
⚙️ HABILIDADES
  • Stun Style: Solo permitido con Blindspot.
  • Fake Shoot: ❌ Prohibido.
  • Direct Shot: ❌ Prohibido dentro del área del GK rival.
  • Blindspot: ❌ No puede utilizarse sobre el GK.
  • Blindspot: Máximo 3 usos por tiempo.
  • Steal Dash: Máximo 3 usos por tiempo.
GAGAMARU
⚙️ HABILIDADES
  • Godspeed + Fast Reaction: ❌ No pueden utilizarse simultáneamente.
  • Awakening: ❌ Prohibido si hay un rival dentro de tu área.
  • Scorpion Kick: ❌ No puede utilizarse mediante M1.
  • Super Reflexes: Solo permitido para pases.
CHIGIRI / NEL CHIGIRI
⚙️ HABILIDADES
  • Godspeed: ❌ Prohibido.
  • Speed Increase + Power Technique: ❌ Prohibido para tiros dentro del área rival.
  • Dashes: ❌ No permitidos dentro del área rival, excepto detrás del punto de penalti.
  • Red Panther Sniper: Debe ejecutarse al menos a 1 línea del área del GK.
  • High-Speed C + Power Flow: ❌ Prohibido.
  • Mini Dash: Comparte la restricción del punto de penalti.
KURONA
⚙️ HABILIDADES
  • Pases: ❌ No pueden dirigirse al área del GK rival.
  • One-Two: Ninguno de los dos jugadores puede estar dentro del área rival.
  • Shark Steal V: Solo permitido en campo propio.
  • Tras One-Two: Esperar 3 segundos antes de realizar Skill Shot.
  • Shark Steal: Máximo 2 robos efectivos por tiempo.
